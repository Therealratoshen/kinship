# Feeling diary

**Why this file exists:** the final gate's central finding was *"measured feeling shift: none
yet."* Six desk-research passes and a labelled simulation license a cheap experiment, not a
platform build. This is the experiment. It costs about ninety seconds per entry, and it is the
only artifact in this repository that can produce a number that wasn't inferred.

Rate **before** you have an opinion about whether the run went well. The point is the delta on
the pair, not a narrative.

---

## How to rate

Pick the position on the 8-step scale. Rate each pole visit separately — do not rate the pair
as one judgment after the fact, and do not average events.

```
Pair 1 — load
overwhelmed ▁▂▃▄▅▆▇█ in control
   1 2 3 4 5 6 7 8

Pair 2 — trust in the gate
dread-of-an-ai-mistake ▁▂▃▄▅▆▇█ confident
   1 2 3 4 5 6 7 8
```

Pair 2 is the interesting one. The empathy-map synthesis predicted it **does not move until the
organiser sees a caught near-miss** — so if Pair 1 improves and Pair 2 doesn't, look at the
near-miss table in the event template before concluding anything.

Optional third pair, if a member-facing lane ran:

```
Pair 3 — identity
curious ▁▂▃▄▅▆▇█ wary
   1 2 3 4 5 6 7 8
```

## Reading your own data honestly

Three ways this measurement can lie, pre-named:

1. **Self-confirmation (n=1, and the n is you).** You drafted the PRD, ran the research, and
   want it to be true. Counterweights: the behavioural checklist outranks your ratings; the
   outsider organiser in W10 is not optional decoration; and the negative-space question
   ("what would make you *not* use this again?") is asked *after* the good feeling, on purpose.
2. **Novelty.** A first run is interesting. Interest reads like relief on a self-report scale.
   Only event #2, four weeks out, distinguishes them — which is why the kill condition is
   behavioural and not attitudinal.
3. **Polite self-praise.** The protocol says it plainly: silence and "it was fine" both count
   as KILL. A flat Pair 1 with no second-event behaviour is a result, not an inconvenience.

> Every published claim about "how organisers feel" must cite a measured before/after delta
> from a filled row of this file, or a behavioural sign. No row → no claim. That is the honesty
> contract's rule for this repository, and it outlives the pilot.
