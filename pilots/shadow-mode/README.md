# Shadow-mode pilot kit

The whole conditional GO reduces to this folder. Everything else in the repository is either
already-written reasoning (`../design-thinking/`) or intent (`../PLAN.md`); the files here are
the only ones that can produce new information.

| File | When you touch it |
|---|---|
| `TEST-PROTOCOL.md` | Once, before the event. Predictions are fixed 2026-10-17 — add results, never edit section 3. |
| `EVENT-TEMPLATE.md` | Copy to `event-<slug>.md` per event. Fill the baseline at T-7, the card log as cards arrive, the verdict after. |
| `FEELING-DIARY.md` | Ninety seconds at T-1 and T+1. This is the measurement the build was waiting on. |
| `OBSERVER-NOTES.md` | Only for the peer/outsider organiser conversations (W10). Not for your own runs. |

**Start sequence:** pick the event → write it as `D9` in `../../DECISIONS.md` → copy the
template → rate the diary at T-1. Nothing else in the plan is real work until step one happens.

**Draft-only means draft-only.** If the fleet sends anything to a member during a shadow run,
the run stops and gets logged as a spec defect (`EVENT-TEMPLATE.md` → Incidents). The point of
the phase is to be unable to hurt anyone while learning whether the feeling moves.
